# SimpleDeckyTDP for ONEXPLAYER 3 (CachyOS)

[English](README.md) | [한국어](README.ko.md) | **日本語** | [繁體中文](README.zh-Hant.md)

Aarron Lee 氏の [SimpleDeckyTDP](https://github.com/aarron-lee/SimpleDeckyTDP) をフォークした個人リポジトリです。TDP・GPU・CPU 関連の機能はすべて元のプロジェクトのもので、このフォークは ONEXPLAYER 3 で CachyOS を使うために必要な部分だけを追加しています。元のプロジェクトとは無関係なので、このビルドの不具合を元のリポジトリに報告しないでください。

OneXPlayer 3 で CachyOS を使うためにいくつか作業を行ったので、そのソースとバイナリを共有します。

Decky Loader をインストールした後、次のスクリプトを実行してインストールしてください。

```bash
curl -L https://github.com/raicoll/SimpleDeckyTDP-OXP3_custom/raw/main/install.sh | bash
```

**元の SimpleDeckyTDP に追加した内容**

- TDP 調整の連携
- ファン速度調整の連携

**その他の追加**

- 明るさと音量の調整 (クイック設定にもある機能ですが、こちらにも追加しました)
- サウンドカードの切り替え (USB サウンドデバイスを複数使うときに切り替えやすくなります)

## 元の版との違い

- **ファン制御 (ONEXPLAYER 3 専用)。** TDP スライダーの下に 静音・自動・標準・最大 の 4 段階スライダーがあり、現在の RPM とおおよその目標 RPM を表示します。
  - 静音: 50°C 以下ではファンを止め、それより高いと最低速度で回します。
  - 自動: ファン制御を組み込みコントローラー (EC) に任せます。
  - 標準: CPU 温度に合わせて曲線で調整します (45°C で約 1100 RPM から 82°C で約 4800 RPM まで)。速度はゆっくり変わり、下げるときは直近 60 秒間の最高温度を基準にします。負荷が一定でもセンサーの値が 3〜4°C 上下するためです。そのため境目の温度付近でうるさくなったり静かになったりを繰り返しません。
  - 最大: 約 4700 RPM です。80°C 以上ではさらに上げます (約 4800 RPM 以上)。
  - 安全対策: 目標値は 180 を超えません (この機種では 185 以上でファンが止まります)。80°C 以上ではファンを最大にし、プラグインの終了時には EC の自動モードに戻します。
- **過熱時の TDP 自動低下 (任意)。** 80°C になると 75°C に戻るまで TDP を少しずつ下げ (指定した下限より下には下げません)、72°C まで冷えるとゆっくり戻します。85〜100°C で長く使うと USB-C ワイヤレスオーディオドングルの接続が繰り返し切れ、70°C まで下げると高負荷のゲームでの損失が大きすぎるため、75°C を目標にしています。保存済みのプロファイルは変わらず、制限中は TDP スライダーに実際の値が表示されます。
- **クイックコントロール。** CPU 温度と消費電力、画面の明るさ、音量、ミュート、出力デバイスを、アイコンとスライダーを 1 行に並べたコンパクトなレイアウトで表示します。
- **表示オプション。** CPU の概要、明るさと音量、出力デバイス、TDP 制御とその詳細をそれぞれ表示・非表示にでき、TDP 制御を上に置いたり、このプラグインのタブをクイックアクセスメニューの一番上に移動したりできます。
- **専用のクイックアクセスタブ**を Decky タブのすぐ上に追加します。
- **ONEXPLAYER 3 の最大 TDP は 40 W。** ファームウェアが 25 W と報告するため、元のプラグインではスライダーが 25 W で止まります。別の上限にするには `$HOME/homebrew/settings/SimpleDeckyTDP/settings.json` の `INTEL_MAX_TDP_SETTING` を変更してください。
- **翻訳**: 英語、韓国語、日本語、簡体字中国語、繁体字中国語。
- **OTA アップデートを無効化。** 元のプロジェクトの更新でこのビルドが誤って上書きされないようにしています。

ファン制御、明るさ、オーディオの機能は追加設定なしで動作します。ファン制御は DMI の製品名が `ONEXPLAYER 3` と完全に一致する場合のみ有効で、ほかの機器ではクイックコントロール以外は元の版と同じように動作します。

## ONEXPLAYER 3 についての注意

- `oxpec` カーネルドライバーがまだこの機種に対応していないため、`ec_sys` モジュールで ACPI EC に直接アクセスしてファンを制御します。プラグインが `write_support=1` でモジュールを読み込むので、カーネルパラメーターは不要です。ファンが手動モードの間は、EC のターボボタン引き継ぎビット (レジスタ 0xEB の 0x40、`oxpec` ドライバーが OneXPlayer 2・X1 で使うものと同じ) もオンにします。このビットがオフだと、EC が独自の曲線でファン速度を上書きし続けます。
- PowerTools などほかの TDP プラグインと同時に使わないでください。先に Decky で無効にしてください。PowerTools がインストールされている場合はインストールスクリプトが知らせます。
- Handheld Daemon (HHD) などほかのツールもファンを制御している場合は、そちらのファン制御をオフにして EC の取り合いを避けてください。
- この機器のパネルでは Steam 標準の明るさスライダーが動作しないため、明るさスライダーを入れています。
- Steam のパフォーマンスオーバーレイは CPU の電力センサーを読むので、追加のパッチなしでこのプラグインが設定した TDP が反映されます。
- ここで出力デバイスを切り替えると Steam の出力デバイスも切り替わるので、本体の音量ボタンで選んだデバイスの音量を調整できます。
- **既知の問題:** 起動後、画面が表示されるまで約 1 分かかります。2026 年 10 月 5 日時点では、まだ解決方法はないようです。

## このフォークの削除

元の SimpleDeckyTDP が ONEXPLAYER 3 に対応したら、このビルドを削除して Decky ストアから元の版をインストールしてください。

```bash
sudo rm -rf $HOME/homebrew/plugins/SimpleDeckyTDP
sudo systemctl restart plugin_loader.service
```

設定は `$HOME/homebrew/settings/SimpleDeckyTDP` に残り、元のプラグインと互換性があります。

元の SimpleDeckyTDP の説明 (英語) は [README.md](README.md#simpledeckytdp-original-readme) にあります。
